Ved lag 14 stopper du 3D-printeren, indsætter en 5x2mm magnet og genoptager printet.
Ved lag 26 skal der skiftes filament.

# Link og knap

Disse dele samles med lidt superlim efter printet. Vi påførte limen på kanten med en tandstik, lige før delene blev lukket sammen.

Vil du have klik-effekten, skal knapkomponenterne presses på plads her, inden delene samles.

# Radioknap og tjekboks

Ligesom ved link og knap kan 5mm-trykknapperne også bruges her til at give klikket. Pres først trykknappen ned, og sæt derefter "hætten" med den bevægelige knap indeni på. Delene kræver ikke lim, de kan bare trykkes eller bankes på plads.

# Toggle

Cirklen limes på, når toggle'en er samlet. En smule olie kan få den til at glide mere jævnt.
